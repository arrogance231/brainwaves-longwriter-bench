# 1M YaRN×4 report

Status: **EXPERIMENTAL / FAILED PILOT**

This profile targets 1,010,000 tokens with static YaRN factor 4.0. It is a
runtime extension of a checkpoint whose actual native limit is 262,144; it is
not a native 1M model.

## Pilot result

The vLLM 0.28.0 ROCm server loaded the profile and accepted one approximately
1M-token nested fiction request. With BF16 weights and BF16 KV, VRAM reached
approximately 184,027,217,920 bytes and GPU utilization reached 100%, but no
first token arrived within the bounded 300-second pilot. The runner was
stopped to release the GPU; no completion was available for quality scoring.

See [`yarn1m-pilot-status.json`](../results/aggregate/yarn1m-pilot-status.json)
for the machine-readable record.

## Decision

Classification: **EXPERIMENTAL** as a launchable research profile, **FAILED** as
a usable serving target in this run. Do not advertise 1M writing capability or
route Story OS requests to it until a future runtime/kernel change produces a
completion and it passes the same retrieval, continuity, and prose gates as the
native control.
