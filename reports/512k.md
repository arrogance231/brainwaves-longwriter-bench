# 512K YaRN×2 report

Status: **EXPERIMENTAL / NOT USABLE IN THIS RUN**

This profile uses static YaRN factor 2.0 with the checkpoint's complete Qwen
partial-MRoPE fields. It is not a native 512K model.

## Pilot result

The vLLM 0.28.0 ROCm server loaded the profile and accepted a single nested
fiction request targeting 524,288 tokens. With BF16 weights and BF16 KV, the
request consumed approximately 182,002,954,240 bytes of VRAM and drove the GPU
to 100%, but produced no first token in about 540 seconds. The runner was
stopped to release the GPU; the server stayed healthy until it was stopped.

This is evidence of runtime acceptance and severe prefill latency, not evidence
of usable 512K writing quality. No retrieval or prose score is assigned because
there was no completion to score.

See [`yarn512-pilot-status.json`](../results/aggregate/yarn512-pilot-status.json)
and the reproducible launcher in [`serving/vllm/start.sh`](../serving/vllm/start.sh).

## Decision

Classification: **EXPERIMENTAL** as a launchable profile, **FAILED** as a
production serving target for this runtime/configuration. Re-test only after
reducing prefill cost or changing runtime/kernel support; do not route normal
story requests here.
