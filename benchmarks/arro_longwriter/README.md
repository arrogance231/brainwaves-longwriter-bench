# Arro LongWriter Bench fixtures

This directory is an original, synthetic benchmark adaptation. The scenario
borrows only the high-level marriage-practical school premise and the names
specified in the project brief. All event descriptions and prose below are
written for evaluation and are not copied from source media.

The corpus is nested: a larger target contains the smaller target's stable
prefix and events. This makes 8K–1M degradation curves comparable. The event
ledger is the machine ground truth; the model is asked to answer targeted
questions before continuing a scene so retrieval and writing can be scored
separately.
