# Arro LongWriter Bench

This benchmark is a newly written, deterministic adaptation/AU for evaluating
long-form state use. Arro replaces Jirō Yakuin in a high-level school marriage-
practical premise. Arro is assigned to Akari; Shiori is Arro's childhood friend;
Minami is Arro's extremely handsome male best friend. Arro compulsively tries to
help Minami find a girlfriend before attending to his own romantic chances.

The running joke must evolve into friendship, jealousy, guilt, and reciprocal
agency rather than reducing Minami to a plot coupon. Character names and the
high-level premise are not source passages. All prose in fixtures is original.

The gold state tracks event IDs, token regions, participants, locations, facts,
knowledge changes, emotional changes, promises, secrets, possessions, injuries,
and callback targets. See `benchmarks/arro_longwriter/gold_state/`.
